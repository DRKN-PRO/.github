# DRKN organization defaults

This repository owns the DRKN GitHub organization profile and default
community-health files. It contains no application or production runtime code.

- Public profile: `profile/README.md`
- Contribution policy: `CONTRIBUTING.md`
- Security policy: `SECURITY.md`
- Issue and pull-request defaults: `.github/`

Application source authority remains in `drkn-web`, `drkn-backend`,
`drkn-content`, and `drkn-infra`.
